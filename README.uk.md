# Gothic 3 ImpExp — аддон Blender для Gothic 3

[English](README.md) · **Українська**

Імпорт і експорт моделей, персонажів, анімацій і колізії **Gothic 3** (Piranha Bytes, 2006, рушій Genome) у
**Blender 5.1+** — прямо з архівів гри й назад у гру.

> **Стан: бета 0.9.** Усе, що пише аддон, звірено з файлами самої гри й прочитано назад через пошук файлів гри, але
> в самій грі ще не пройдено. Зробіть резервну копію й повідомляйте, що знайдете.

## Що він уміє

**File → Import** (пошук за назвою в межах категорії):

| Пункт | Файли гри | Що з'являється в Blender |
|---|---|---|
| Gothic 3 Model | `.xcmsh` + `.xshmat` + `.ximg` | меш з текстурами (вершини зварені, шви uv/нормалей збережені), налаштовані alpha test/blend і specular, і його колізія — каркасний дочірній об'єкт `<назва>_COL`. Категорії: предмети, будівлі, декор і меблі, рослини, локації, рельєф, вода, службові |
| Gothic 3 Character | `.xact` | скелет (кістки паличками) і меш зі шкінінгом, без анімації; тіло людини — з вибраною головою (типово голова Безіменного). Категорії: люди — тіло або голова, тварини й монстри, предмети й об'єкти |
| Gothic 3 Animations | `.xmot` | анімації на вибраний скелет Gothic 3: одна або ціла категорія — стійка, рух, атаки, захист, діалоги й жести, сидіння й лежання, взаємодія, смерть |
| Gothic 3 Collision | `.xnvmsh` | лише колізія, каркасним мешем; по матеріалу `G3_Shape_<поверхня>` на кожну поверхню (камінь, дерево, земля…). У клітинок рельєфу колізія — їхні ж трикутники |

**File → Export** (встановити в гру або зібрати пакет мода з `INSTALL.bat` / `ROLLBACK.bat`):

| Пункт | Що пише |
|---|---|
| Gothic 3 Model → Mod | `.xcmsh` замість моделі гри з тією ж назвою або нову, нові матеріали (`.xshmat` за шаблонами гри: непрозорий, з блиском, з alpha test) і текстури (`.ximg`), колізію (`.xnvmsh`, з об'єктів `*_COL` або з самої моделі; у рельєфу — завжди з моделі) з поверхнями за матеріалами. Заміна моделі гри бере кольори вершин і освітлення (лайтмапи всіх її розміщень у світі) від найближчих старих вершин і заміняє також її `_lod1` |
| Gothic 3 Motion → Mod | `.xmot` замість однієї з анімацій гри (типово тієї, з якої прийшла дія) або нова анімація поруч; IK та інші обмеження потрапляють як результат; ефекти кадрів (кроки, звуки) — зі списку дії, що редагується у вкладці Gothic 3 |
| Gothic 3 Actor → Mod | `.xact` — ваш меш на скелеті гри (броня, тіла, голови, істоти з одним мешем), ваги з груп вершин |

Моди потрапляють у гру як том-латка на кожен архів (`Data\_compiledMesh.pNN` тощо, після власних томів гри) — так само,
як латки самої гри; архіви не змінюються. Вкладка **Gothic 3** показує встановлені з Blender моди з кнопкою «прибрати».

Вкладка **Gothic 3** у бічній панелі 3D-вікна має все це, а коли вибрано скелет Gothic 3 — **риг для анімування**:
кольори й групи кісток, фігури, за які зручно хапати, і IK для рук і ніг (ціль і полюс на кожну кінцівку). Риг лише
додає кістки, які нічого не деформують; IK спершу вимкнено, а вмикання кінцівки ставить ціль точно в поточну позу.

## Встановлення

1. Blender 5.1 або новіший.
2. *Edit → Preferences → Get Extensions → ⌄ → Install from Disk…* → `gothic3_impexp-0.9.3.zip`.
3. У налаштуваннях аддона перевірте **Папка гри Gothic 3** (та, де лежить `Gothic3.exe`; шлях Steam уже
   підставлено).

Zip містить `gothic3-core.exe` — нативну частину (Windows x64). Більше нічого не потрібно — ні PhysX SDK, ні програм.
Встановлені моди лежать у `Gothic 3\gothic3_impexp\` (їхні файли й список) плюс по одному тому-латці на архів у `Data`.

## Швидкий старт

- **Замінити предмет:** Import → Gothic 3 Model → `G3_Object_Barrel_02`. Змініть його, не зсувайте початок координат.
  Export → Gothic 3 Model → Mod, та сама назва, *Встановити в гру*. Запустіть гру.
- **Нова броня:** Import → Gothic 3 Character → `G3_Hero_Body_Player`. Змініть меш тіла (лишіть шкінінг), виділіть лише
  його, Export → Gothic 3 Actor, та сама назва. Голова — окремий актор: виділіть лише її, щоб експортувати.
- **Змінити анімацію:** Import → Gothic 3 Character → істота, виділіть скелет, Import → Gothic 3 Animations. Змініть дію
  (допоможе риг для анімування), Export → Gothic 3 Motion: анімацію, з якої вона прийшла, уже вибрано.

## Обмеження (0.9)

- Меші пишуться як у гри (елементи версії 5 з кольорами вершин і деревом сфер), але без другого набору uv: освітлення
  заміненої моделі пишеться вершинним (так у грі три чверті лайтмап), навіть якщо в гри воно було сторінками-текстурами.
- Далекі низькополігональні версії світу (`*_lowpoly`, `G3_World_Landscape_Lowpoly_*`) не замінюються.
- Колізія кукається за правилами Gothic 3 (дерево зіткнень, прапорці опуклих ребер — як у гри); прапорці вершин
  (для згладжування контактів) рахуються простіше, ніж у гри.
- Нова анімація бере анімацію гри за зразок (її кістки й структуру); актори — лише заміняти актора гри з одним мешем
  (або стати поруч).
- Нова модель чи актор з'являються в грі лише тоді, коли щось їх розставляє або на них посилається.

## Примітки

- **Поверхня колізії** (звук кроків): панель матеріалу → Gothic 3 → *Поверхня колізії*. Авто — з назви: матеріали рельєфу
  гри мають свою (трава й лісова підстилка = clay, гравій = debris, стежки = earth, скелі = stone, пісок = sand), інші —
  за словами в назві (wood, metal, stone…), решта — типова з діалогу експорту.
- Імпорт кількох моделей з тим самим матеріалом гри дає один спільний матеріал (без `.001`), меші лишаються окремими.
- Gothic 3 рахує в сантиметрах; аддон імпортує з масштабом 0.01 (метри).
- Томи-латки (`.p00`, `.p01`, … Community Patch) читаються поверх основних архівів, як це робить гра.
- Доріжка анімації задана відносно найближчого предка, який теж має доріжку; службові кістки між ними
  (`*_ROOT`, `*_END`) під час програвання тримаються одиничними, як у грі.

